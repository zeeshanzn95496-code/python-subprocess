================================================================================
PYTHON SUBPROCESS MODULE - COMPREHENSIVE GUIDE
================================================================================

OVERVIEW:
----------
The subprocess module in Python is a built-in library that allows you to run 
external programs and system commands directly from your Python code.

In simple words, it allows Python to communicate with your computer's terminal 
(CMD, PowerShell, or Bash).

KEY FUNCTIONS:
--------------

1. subprocess.run() - The recommended way to run subprocess commands
   - Parameters:
     * args: Command to run (list or string)
     * shell: If True, runs command through shell (string args required)
     * capture_output: If True, captures stdout and stderr
     * text: If True, returns output as string (not bytes)
     * check: If True, raises CalledProcessError on non-zero exit code
     * cwd: Working directory for the command
     * env: Environment variables

2. subprocess.Popen() - Advanced control over subprocess execution
   - Provides more control over input/output streams
   - Allows communication with running processes

3. subprocess.call() - Runs command and returns exit code
   - Similar to run() but simpler

4. subprocess.check_call() - Runs command and raises error on failure
   - Automatically checks return code

5. subprocess.check_output() - Returns command output
   - Raises CalledProcessError if command fails

6. subprocess.getoutput() - Returns output of command (deprecated)
   - Uses shell by default

7. subprocess.getstatusoutput() - Returns (exit_code, output) tuple (deprecated)

RETURN OBJECT (CompletedProcess):
----------------------------------
When using subprocess.run(), it returns a CompletedProcess object with:
- returncode: Exit code of the command (0 = success)
- stdout: Standard output (if captured)
- stderr: Standard error (if captured)
- args: Arguments used to run the command

ERROR HANDLING:
---------------
Two main approaches:
1. Check returncode manually:
   if result.returncode == 0:
       print("Success")
   else:
       print("Error:", result.stderr)

2. Use check=True with try/except:
   try:
       subprocess.run(["command"], check=True)
   except subprocess.CalledProcessError:
       print("Command failed!")

SECURITY CONSIDERATIONS:
------------------------
- Avoid shell=True when possible (security risk)
- Use list format for arguments instead of strings
- Validate user input before passing to subprocess
- Don't pass sensitive data through command line

EXAMPLE COMMANDS:
-----------------

# Basic command execution
subprocess.run(["echo", "hello"])

# With shell (for shell commands)
subprocess.run("echo hello", shell=True)

# Capture output
result = subprocess.run(["git", "status"], capture_output=True, text=True)
print(result.stdout)

# Error handling with check
try:
    subprocess.run(["git", "push"], check=True)
except subprocess.CalledProcessError:
    print("Git push failed")

# Working directory
subprocess.run(["npm", "install"], cwd="/path/to/project")

# Environment variables
import os
env = os.environ.copy()
env["MY_VAR"] = "value"
subprocess.run(["command"], env=env)

BEST PRACTICES:
---------------
1. Use list format for arguments when possible (safer)
2. Avoid shell=True unless necessary
3. Always use text=True for string output
4. Handle errors appropriately
5. Validate user input before passing to subprocess
6. Use capture_output=True when you need the output
7. Consider timeout for long-running commands
