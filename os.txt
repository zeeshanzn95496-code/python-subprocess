PYTHON OS MODULE - COMPREHENSIVE GUIDE
================================================================================

OVERVIEW:
----------
The os module in Python is a built-in library that provides a portable way of 
using operating system-dependent functionality. It allows you to interact with 
the file system, environment variables, processes, and other OS-level operations.

In simple words, it's the bridge between your Python code and your computer's 
operating system (Windows, macOS, Linux).

KEY FUNCTIONS:
--------------

1. os.getcwd() - Get Current Working Directory
   - Returns the current working directory as a string
   - Example: print(os.getcwd())

2. os.chdir(path) - Change Directory
   - Changes the current working directory
   - Example: os.chdir('/path/to/directory')

3. os.listdir(path='.') - List Directory Contents
   - Returns a list of files and directories in the specified path
   - Example: files = os.listdir('/path/to/folder')

4. os.mkdir(path) - Create Directory
   - Creates a new directory (single level)
   - Raises error if directory already exists
   - Example: os.mkdir('new_folder')

5. os.makedirs(path) - Create Multiple Directories
   - Creates intermediate directories if they don't exist
   - Example: os.makedirs('parent/child/grandchild')

6. os.rmdir(path) - Remove Directory
   - Removes an empty directory
   - Raises error if directory is not empty
   - Example: os.rmdir('empty_folder')

7. os.removedirs(path) - Remove Multiple Directories
   - Removes empty directories recursively
   - Example: os.removedirs('parent/child/grandchild')

8. os.remove(path) - Remove File
   - Deletes a file (not a directory)
   - Example: os.remove('file.txt')

9. os.rename(src, dst) - Rename File/Directory
   - Renames a file or directory
   - Example: os.rename('old.txt', 'new.txt')

10. os.path.exists(path) - Check if Path Exists
    - Returns True if path exists, False otherwise
    - Example: if os.path.exists('file.txt'):

11. os.path.isfile(path) - Check if Path is a File
    - Returns True if path is a file
    - Example: if os.path.isfile('document.txt'):

12. os.path.isdir(path) - Check if Path is a Directory
    - Returns True if path is a directory
    - Example: if os.path.isdir('folder'):

13. os.path.join(path1, path2, ...) - Join Paths
    - Joins path components intelligently
    - Handles OS-specific path separators
    - Example: full_path = os.path.join('folder', 'file.txt')

14. os.path.abspath(path) - Get Absolute Path
    - Returns the absolute path of a file/directory
    - Example: abs_path = os.path.abspath('file.txt')

15. os.path.basename(path) - Get Filename
    - Returns the final component of a path
    - Example: name = os.path.basename('/path/to/file.txt') # returns 'file.txt'

16. os.path.dirname(path) - Get Directory Name
    - Returns the directory component of a path
    - Example: dir = os.path.dirname('/path/to/file.txt') # returns '/path/to'

17. os.path.split(path) - Split Path
    - Splits path into (head, tail) tuple
    - Example: head, tail = os.path.split('/path/to/file.txt')

18. os.path.splitext(path) - Split Extension
    - Splits path into (root, ext) tuple
    - Example: root, ext = os.path.splitext('file.txt') # returns ('file', '.txt')

19. os.getenv(key, default=None) - Get Environment Variable
    - Returns the value of an environment variable
    - Example: home = os.getenv('HOME')

20. os.environ - All Environment Variables
    - Dictionary-like object containing all environment variables
    - Example: print(os.environ['PATH'])

21. os.name - Operating System Name
    - Returns the name of the operating system
    - 'nt' for Windows, 'posix' for Unix/Linux/macOS
    - Example: print(os.name)

22. os.stat(path) - File Statistics
    - Returns file statistics (size, permissions, etc.)
    - Example: stats = os.stat('file.txt')

23. os.walk(path) - Walk Directory Tree
    - Generator that yields (dirpath, dirnames, filenames) tuples
    - Useful for recursive directory traversal
    - Example: for root, dirs, files in os.walk('.'): ...

24. os.system(command) - Execute System Command
    - Executes a command in the system shell
    - Note: subprocess module is preferred for new code
    - Example: os.system('ls -la')

25. os.getpid() - Get Process ID
    - Returns the current process ID
    - Example: pid = os.getpid()

================================================================================
COMMON PATTERNS AND BEST PRACTICES
================================================================================

Pattern 1: Safe Directory Creation
-----------------------------------
if not os.path.exists(path):
    os.makedirs(path)
# This prevents errors if directory already exists

Pattern 2: Working with Paths Cross-Platform
--------------------------------------------
# Use os.path.join instead of hardcoding separators
file_path = os.path.join('folder', 'subfolder', 'file.txt')
# Works on Windows, macOS, and Linux

Pattern 3: Checking File Before Operations
-----------------------------------------
if os.path.isfile(path):
    # Safe to perform file operations
    os.remove(path)

Pattern 4: Recursive Directory Traversal
----------------------------------------
for root, dirs, files in os.walk(start_path):
    for file in files:
        file_path = os.path.join(root, file)
        # Process each file

Pattern 5: Temporary File Handling
-----------------------------------
import tempfile
temp_dir = tempfile.mkdtemp()
try:
    # Do work with temp directory
    pass
finally:
    # Clean up
    os.rmdir(temp_dir)

Pattern 6: Environment-Specific Paths
--------------------------------------
# Get user home directory cross-platform
home = os.path.expanduser('~')
config_path = os.path.join(home, '.config', 'myapp')

Best Practices:
---------------
1. Always use os.path.join() for path construction
2. Check if paths exist before operations
3. Handle exceptions (FileNotFoundError, PermissionError)
4. Use os.path.abspath() for absolute paths when needed
5. Clean up temporary files and directories
6. Use os.walk() for recursive operations
7. Check file permissions before operations
8. Use context managers for file operations
9. Validate user input for paths
10. Consider using pathlib for newer Python code (more modern API)

================================================================================
OS MODULE VS SUBPROCESS MODULE
================================================================================

OS Module:
- Used for file system operations
- Direct interaction with files and directories
- Path manipulation
- Environment variables
- Process management basics

Subprocess Module:
- Used for running external commands
- Execute system commands and programs
- Capture command output
- More control over process execution
- Preferred over os.system() for new code

When to use which:
- Use os module for file/directory operations
- Use subprocess module for running commands/programs
- They can be used together in the same project

Example 1: File Organizer
--------------------------
import os
import shutil

def organize_files(source_dir):
    extensions = {
        '.txt': 'documents',
        '.jpg': 'images',
        '.png': 'images',
        '.pdf': 'documents',
        '.mp3': 'music'
    }
    
    for file in os.listdir(source_dir):
        file_path = os.path.join(source_dir, file)
        if os.path.isfile(file_path):
            ext = os.path.splitext(file)[1]
            if ext in extensions:
                target_dir = os.path.join(source_dir, extensions[ext])
                os.makedirs(target_dir, exist_ok=True)
                shutil.move(file_path, os.path.join(target_dir, file))

Example 2: Directory Size Calculator
-------------------------------------
import os

def get_dir_size(path):
    total_size = 0
    for dirpath, dirnames, filenames in os.walk(path):
        for file in filenames:
            file_path = os.path.join(dirpath, file)
            total_size += os.path.getsize(file_path)
    return total_size

Example 3: Find Files by Pattern
---------------------------------
import os

def find_files(pattern, path):
    matches = []
    for root, dirs, files in os.walk(path):
        for file in files:
            if pattern in file:
                matches.append(os.path.join(root, file))
    return matches

Example 4: Clean Old Files
---------------------------
import os
import time

def clean_old_files(directory, days_old=30):
    cutoff = time.time() - (days_old * 86400)
    for root, dirs, files in os.walk(directory):
        for file in files:
            file_path = os.path.join(root, file)
            if os.path.getmtime(file_path) < cutoff:
                os.remove(file_path)
                print(f"Removed: {file_path}")

================================================================================
SECURITY CONSIDERATIONS
================================================================================

1. Path Traversal Prevention
   - Validate user input for paths
   - Use os.path.abspath() to resolve paths
   - Check if resolved path is within allowed directory

2. Permission Errors
   - Check file permissions before operations
   - Handle PermissionError exceptions
   - Don't assume write access

3. Symbolic Links
   - Be aware of symlinks when using os.walk()
   - Can cause infinite loops if not handled
   - Use os.path.realpath() to resolve symlinks

4. Race Conditions
   - File can be deleted between exists() check and operation
   - Use try/except instead of exists() checks when possible
   - Handle errors gracefully

5. Sensitive Data
   - Be careful with environment variables
   - Don't log sensitive file paths
   - Secure temporary files appropriately

================================================================================
MODERN ALTERNATIVE: PATHLIB
================================================================================

Python 3.4+ includes pathlib, a more modern object-oriented approach:

from pathlib import Path

# Instead of:
# os.path.join('folder', 'file.txt')

# Use:
path = Path('folder') / 'file.txt'

# Path objects have methods:
path.exists()
path.is_file()
path.is_dir()
path.mkdir()
path.rmdir()
path.unlink()  # remove file

Many developers prefer pathlib for new projects, but os module is still 
widely used and supported.
